# v0.1.0 release notes (draft)

This milestone packages the GTpro research snapshot as an installable Python
project. It adds deterministic pretraining-data preparation and reports,
config-driven CPU smoke pretraining, unified BACE/Tox21/Lipophilicity
fine-tuning entry points, bounded tests, and artifact policies.

Known limits: smoke outputs are not benchmark results; full data and weights
are excluded; redistribution remains subject to the original GTpro license
clarification in `LICENSE_SCOPE.md`. This file is a release-note draft, not
evidence that a Git tag or hosted release exists.
