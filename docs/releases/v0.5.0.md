# v0.5.0 release notes (draft)

This milestone adds the frozen compact reproduction protocol, a one-epoch
11,988-molecule compact pretraining run, three-seed random/scaffold downstream
runs, classical and representation baselines, objective ablations, generated
tables/plots, and lightweight trace records.

The measured 64-dimensional results are project reproduction evidence, not the
paper's reported values and not a state-of-the-art claim. Paper-scale training,
ToxCast, and pairwise interaction tasks remain outside the validated scope.
This file does not claim that a Git tag or hosted checkpoint has been published.
