# v1.0.0 release notes (draft)

This milestone adds the stable `GTproEncoder` graph/text/joint API,
architecture and reproducibility documentation, citation and contribution
metadata, CPU-only CI workflow definition, clean-environment verification, and
the public-release audit.

Before publication, maintainers must obtain or document permission for the
original GTpro-derived files, push the repository, observe a successful remote
GitHub Actions run, create the actual tags/releases, and host any formal
checkpoint outside Git with checksum and model-card metadata. Until those
external steps occur, this is a complete release-note draft rather than a
published `v1.0.0` release.
